# SubEquipe 01 — GoF Criacionais

Exemplo didático do padrão Builder aplicado à construção de publicações para um fórum, em JavaScript com Node.js.

## Executar

```bash
node src/index.js
node --test
```

A implementação é independente e não afirma estar integrada ao sistema principal do Projeto Fórum. Preencha as seções de evidências e uso de IA com os registros reais da equipe.
