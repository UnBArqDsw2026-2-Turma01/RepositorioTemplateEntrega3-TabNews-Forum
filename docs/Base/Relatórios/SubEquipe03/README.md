# SubEquipe 03 — GoF Comportamentais

Exemplo didático do padrão Observer aplicado aos eventos de conteúdo de um fórum, em JavaScript com Node.js.

## Executar

```bash
node src/index.js
node --test
```

A implementação é independente e não afirma estar integrada ao sistema principal do Projeto Fórum. A documentação do código e da execução está nas páginas `código.md` e `execução.md` desta subequipe.
