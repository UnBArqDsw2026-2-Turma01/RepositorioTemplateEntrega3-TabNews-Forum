## Sobre

O projeto tem como objetivo documentar e aplicar padrões de projeto GoF (Gang of Four), explorando soluções recorrentes para problemas relacionados à criação de objetos, à organização estrutural das classes e à interação entre objetos no desenvolvimento de software.

Nesta terceira entrega, os integrantes foram organizados em três subequipes, responsáveis pelo estudo e desenvolvimento de padrões criacionais, estruturais e comportamentais, respectivamente. Os artefatos produzidos contemplam a modelagem, a implementação em código, a demonstração da execução dos padrões e a análise do uso da Inteligência Artificial Generativa durante o processo de desenvolvimento.

A documentação também apresenta as justificativas das decisões tomadas, as relações com artefatos desenvolvidos em etapas anteriores, as referências utilizadas e os registros das contribuições individuais dos integrantes.
